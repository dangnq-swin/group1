# First group project

## General requirements

Instructions:
  - HTML5 and CSS3 only
  - 4 pages, `index.html`, `jobs.html`, `apply.html` and `about.html`
  - Common navigation menu, valid HTML5, and valid semantic tags, meaning we
  prefer specific tags like `<nav>` or `<footer>` over general `<div>`
  - Chosen G04 "A technology company developing digital learning tools and
  platforms, seeking web developers and designers to support accessible and
  inclusive online education services."
  - Page content must look professional, communicate clearly what the purpose
  of the page is.

Technical CSS:
  - At least one embedded CSS example on every web page
  - At least one inline CSS example on every web page
  - Clear comments + selectors
  - Responsive + accessibility (semantic tags + alt)
  - index.html: Background graphic using CSS
  - jobs.html: <aside> floated right, 25% width, styled with margin, padding, and border
  - about.html: Styled student IDs, bordered figure, styled table with hex colours and hover effects
  - apply.html: Form layout using Flexbox or Grid
